== 1. The two error rates (arm filter 94 MHz, two poles: Rice's nu0 = 94 MHz)
   false events from an idle that crosses a threshold u sigma away, one comparator:
     one a second   u = 6.06 sigma
     one an hour    u = 7.29 sigma
     one a day      u = 7.71 sigma
   a wrong message once in 1e+03     z = 3.09 sigma
   a wrong message once in 1e+04     z = 3.72 sigma
   a wrong message once in 1e+06     z = 4.75 sigma
   design point: 2.8e-04 false event a second (one an hour) and 1e-04 wrong messages: idle side 7.29 sigma, message side 3.72
   so the idle wants 11.01 sigma to every message and the messages 7.44 to each other: a ratio of 1.48, not 1
   (sim/link_rates.py's 'quiet' is 1e-4 per decision: at 9e+07 decisions a second that is 9e+03 false events a second)
